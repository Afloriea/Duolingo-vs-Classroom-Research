# survey_responses.csv

57 anonymous responses to the Qualtrics survey posted on r/languagelearning (May 2024). The survey collected no names, emails or other identifying details.

| Column | Meaning |
|---|---|
| `age`, `education`, `native_language` | Respondent background (age is optional, so some values are blank) |
| `foreign_language` | Languages being learned, comma-separated |
| `proficiency` | Self-rated level on the ILR scale |
| `learning_method`, `learning_method_other` | Methods used (multi-select + free-text "Other") |
| `most_effective`, `most_effective_other` | Methods found most effective (multi-select + free-text "Other") |
| `time_allocated` | Hours per week spent learning |
| `budget` | Money spent on learning (USD) |
| `f_cost` … `f_flexibility` | Rank of each factor, 1 = most important, 6 = least |
| `taking_class` | Currently taking a class in the language |

Free-text explanations of why a method was or wasn't effective were left out of this file. In three rows, the `learning_method` list was cut off in the original export after "Self-Study".
